# CVL Final

## Deploy on GitHub Pages

This project is ready to be published on GitHub Pages, which is a free hosting option for static sites.

- GitHub Pages documentation: https://pages.github.com/
- GitHub repository settings for Pages: https://github.com/settings/pages

### Quick deployment steps

1. Push this repository to GitHub.
2. Open your repository's GitHub Pages settings and enable Pages.
3. Run the deploy command:

   npm run deploy

4. After publishing, the site will be available at:

   https://<your-username>.github.io/CVLFinal/
